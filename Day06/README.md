# Reeborg's World – Maze

This project is a solution to the **Maze** challenge from Angela Yu's *100 Days of Code: The Complete Python Pro Bootcamp*.

> **Note:** My solution uses a different approach from the one demonstrated in the course. I came up with my own logic to solve the maze.

## 🌐 Run in Reeborg's World

**[Open Reeborg's World – Maze](https://reeborg.ca/reeborg.html?lang=en&mode=python&menu=worlds%2Fmenus%2Freeborg_intro_en.json&name=Maze&url=worlds%2Ftutorial_en%2Fmaze1.json)**

### How to run

1. Open the link above.
2. Copy the code from `maze.py`.
3. Paste it into Reeborg's Python editor.
4. Click **Run**.

> This project is designed specifically for Reeborg's World and will not run as a standalone Python program.
